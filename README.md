# 🛣️ Road for Data Scientist

Welcome to my central repository for all things Data Science and Machine Learning! 

As an AI and computer applications student, I created this space to document my hands-on progress. This repository contains my code, experiments, and projects as I build a strong foundation in data analytics, statistical modeling, and predictive algorithms.

## 🧰 The Toolkit
All projects in this repository are developed using **Google Colab**, making it incredibly easy to view and execute the code.

* **Programming & Querying:** Python, SQL
* **Data Wrangling & EDA:** NumPy, Pandas
* **Machine Learning:** Scikit-Learn (Regression, Classification, Ensembles)
* **Mathematics:** Applied Statistics, Probability, and Linear Algebra

## 📂 Repository Structure
The notebooks here follow a structured learning path:
1. **Data Manipulation:** Cleaning messy data, handling missing values, and utilizing Pandas DataFrames.
2. **Exploratory Data Analysis (EDA):** Extracting insights, visualizing trends, and understanding statistical distributions.
3. **Machine Learning Pipeline:** 
   - Feature engineering and scaling.
   - Splitting datasets for training and testing.
   - Implementing models (like Random Forests and Linear Regression).
   - Evaluating model accuracy and performance metrics.

## 🚀 Getting Started
Feel free to explore the code! 
- Navigate to any `.ipynb` file in this repository.
- You can read the output directly on GitHub, or click the **"Open in Colab"** button (if added) at the top of the notebooks to run the code interactively in your own browser.
